Regras de Preenchimento

  • Link: Deve começar obrigatoriamente com http:// ou https://.
  • WiFi: Preencha o nome da rede (SSID). A senha é opcional.
  • vCard: O Nome Completo é obrigatório. Os outros campos são opcionais.
  • PIX CPF: Insira os 11 dígitos. Sinais gráficos serão formatados automaticamente.
  • PIX Celular: Use o padrão nacional com DDD (ex: 11999999999).
  • PIX E-mail: Deve ser um formato de e-mail válido (ex: exemplo@site.com).
  • Controles Avançados: Use o painel para carregar qualquer logo transparente ou moldura decorativa de marca.
